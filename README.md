# Nexus Görsel

Tarayıcıda çalışan görsel aracı. Dosyalar hiçbir sunucuya yüklenmez.

- Sıkıştırma, boyutlandırma, format çevirme (JPEG / WebP / PNG)
- Hedef dosya boyutu (örn. en fazla 200 KB)
- GPS / EXIF tespiti ve silme
- Kırpma, döndürme, çevirme, metin filigranı
- Önce/sonra karşılaştırma, toplu işlem, ZIP indirme

Tek dosya: `index.html`. Derleme veya kurulum gerekmez.

## GitHub Pages ile yayınlama
1. Dosyaları repo köküne yükle.
2. Settings > Pages > Branch: `main` / `/ (root)` > Save.
3. Birkaç dakika sonra `https://KULLANICI.github.io/REPO/` adresinde açılır.
